# AI QUEST - 8-Bit Learning Game

A single-file, browser-based learning game. There is nothing to install or build.

## How to open it

The game is the file `AI-QUE~1.HTM` (Windows shows a shortened name for it).

1. Download or clone this repository.
2. Double-click `AI-QUE~1.HTM`. It opens in your default browser.

Or open it from a terminal:

```
start "" "AI-QUE~1.HTM"
```

You can also drag the file into an open browser window, or use *File > Open file* (Ctrl+O).

## Notes

- Use any modern browser (Chrome, Edge, Firefox).
- The pixel font (Press Start 2P) loads from Google Fonts, so it needs an internet connection.
  Offline, the game still runs but falls back to a default font.
